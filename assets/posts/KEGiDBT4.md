# HTML 链接与图片

在网页中：

- 
**链接（Link）** 用于页面跳转

- 
**图片（Image）** 用于展示内容

几乎所有网站都离不开这两个核心元素。

本章将学习：

- 
`<a>` 超链接标签

- 
链接的类型与用法

- 
路径（相对路径 / 绝对路径）

- 
`<img>` 图片标签

- 
图片优化与 SEO

学习完本章，你将能够：

- 
构建网站页面之间的跳转

- 
插入并优化网页图片

- 
理解 URL 与路径关系

# 6.1 超链接标签 ``

HTML 使用 `<a>`（anchor）创建链接。

基本语法：

```
[链接文本](URL)
```

示例：

```
[访问网站](https://www.example.com)
```

点击后浏览器会跳转到指定地址。
