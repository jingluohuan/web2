# 中国大陆未成年人办理万事达卡教程，亲测有效

# 前言

众所周知，现在你在一些国外网站上，不管是买服务器还是买东西，中国的银联卡普遍没有什么用，有用的卡只有visa和万事达。但是，visa它普遍是信用卡，未成年人是办不了信用卡的。而万事达卡，他有储蓄卡。

那么这张卡它是所有银行都可以开的吗？答案不是，我是咨询过的，我专门给中国银行、工商银行等银行打了电话，他们都是说未成年人办不了这张卡。

但是，当我打电话给第6家银行的时候，他们的客服和我说可以的。那么这家银行到底是哪家呢？这家银行就是**招商银行。**这家银行的万事达卡也是中国里面用来搞外汇最常用的卡。

# 一：准备工作

导入你要开卡，肯定不能直接去到银行，我们是要做准备的。

## 需要材料：

1.身份证

2.本人户口本

3.父母身份证

4.父母户口本

*因为是未成年人开卡，所以需要叫上家长，并且需要证明亲子关系，准备上述材料就可以了

# 二：银行选择

# 三：开卡注意事项

1.一定要在自助机上面开，人工柜台开出来的没有外汇功能！！！

2.未成年人一定要带上家长，否则是开不了的！！！

3.他会问你卡是用来干嘛的，你需要让你的父母来回答，说是给你存钱的。

4.他会向你推荐一堆金融服务，在你开卡完成之后，你就跟他说什么金融服务都不需要

5.开卡的时候注意，要是万事达不要开银联。如果没有卡，就下一次再来。

6.关于一类卡跟二类卡的说明，我是建议万事达开二类卡，因为它支持境外免密支付，一类卡的额度更高。
而二类卡限额3000

# 四：总结

开卡需要在营业网点开卡，必须在自助机上面开，人工柜台没有外汇功能，最好开二类卡。
