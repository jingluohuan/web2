为了让小慧博客的朋友们在 Minecraft 世界中也能畅玩，小慧博客现已自建一台高品质 Minecraft Java 服务器，欢迎大家加入体验！

**服务器版本**：Java 所有版本

- 
**服务器地址**：`hui.mc.itxiaohui.top:35498`

- 
**支持平台**：Minecraft Java 版

## 如何加入服务器

- 
打开 Minecraft Java 版客户端（版本 1.21.8）

- 
点击 **多人游戏 → 添加服务器**

- 
输入地址：`hui.mc.itxiaohui.top:35498`

- 
点击加入即可进入游戏
