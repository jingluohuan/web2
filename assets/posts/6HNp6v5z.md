## 二、安装教程

### 1. 准备工作

- 
**服务器环境**：

PHP 版本：5.6 及以上（推荐 7.x）

- 
MySQL 版本：5.6 及以上

- 
Web服务器：Apache / Nginx

- 
**数据库**：提前创建一个空数据库，并记录数据库名、用户名、密码。

### 2. 上传文件

将下载好的杰奇CMS 1.8 压缩包上传到网站根目录并解压，确保目录可写权限，以便程序创建缓存和日志文件。

![](assets/png/articles/c8b6fe907221.png)

![](assets/png/articles/6507dae15bd6.png)

### 3. 访问安装页面

在浏览器中访问：

```
http://你的域名/install/
```

进入安装向导界面。

### 4. 填写数据库信息

按提示输入数据库主机、数据库名、用户名和密码，然后点击“测试连接”，确保数据库可用。

### 5. 配置网站信息

设置网站名称、管理员账号、密码及联系邮箱。

### 6. 安装完成

安装完成后，请删除 `install` 目录以保证安全。
后台登录地址：

```
http://你的域名/admin.php
```
