# XHMCL Launcher（小慧MC启动器）正式发布

大家好，经过一段时间的开发与测试，XHMCL Launcher（小慧MC启动器）终于正式发布了！

XHMCL 是一款面向 Minecraft Java Edition 玩家的现代化启动器与游戏管理工具，首个公开版本为 0.8.4，支持 Windows、Linux 和 macOS。我们希望把游戏下载、Java 配置、模组管理、账号登录和本地开服等常用功能整合在一起，让玩家可以更轻松地进入 Minecraft 世界。

## 一站式管理 Minecraft

XHMCL 支持下载安装 Minecraft 原版，并可为游戏实例安装 Forge、Fabric、Quilt 和 NeoForge。不同实例之间相互隔离，可以分别保存模组、配置、存档和启动参数，方便管理不同版本或模组组合。

启动器可以扫描电脑中已有的 Java，也能根据 Minecraft 版本自动下载并匹配 Java 8、17、21或25。玩家还可以导入自己的 Java 可执行文件或 Java 主目录，并支持识别 GraalVM、Dragonwell、Liberica、Semeru、Corretto、Zulu 等发行版。

## 模组、整合包与资源管理

通过资源中心，玩家可以搜索并安装 Modrinth 上的模组、光影、材质包、整合包以及 Paper 插件。

XHMCL 会根据目标实例的 Minecraft 版本和加载器查找兼容资源，并处理必要依赖。已经安装的资源还可以进行启用、禁用、删除、导入和更新检查，减少手动寻找文件、核对版本和整理目录的麻烦。

## 账号与快捷启动

XHMCL 支持 Microsoft 正版账号和离线账号。Microsoft 登录会在系统浏览器和 Microsoft 官方页面中完成，启动器不会要求用户在软件界面输入密码或验证码。

首页提供快捷启动功能，可以读取最近使用的单人世界以及已保存的联机服务器。对于支持的 Minecraft 版本，玩家可以跳过主菜单直接进入世界，也可以快速连接常用服务器。

首页还加入了本地日历、节日彩蛋、每日启动统计和 Minecraft 官方新闻，让启动器不只是一个“启动按钮”，也能成为日常管理 Minecraft 的入口。

## 内置本地开服功能

除了启动客户端，XHMCL 还提供本地开服中心，支持 Vanilla、Paper、Fabric 和自定义服务端核心。

玩家可以配置服务器版本、内存、端口、最大玩家数和 MOTD，并通过图形化界面编辑 `server.properties`。服务器运行后，可以查看实时控制台、发送命令、管理进程，并查看在线玩家列表、头像和皮肤。

## 个性化与实用工具

XHMCL 支持简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语和俄语，并提供深色、浅色及跟随系统主题。

玩家可以导入自定义壁纸、调整背景颜色和窗口透明度，也可以自由显示、隐藏和排列首页板块。

启动器还提供本地音乐播放器、多线程下载器、下载源切换、游戏垃圾清理以及 Windows 内存优化等实用功能。本地音乐播放器支持 MP3、WAV、AIFF、AIF 和 AU 文件，音乐只在电脑本地播放，不会上传到 XHMCL 或第三方服务。
