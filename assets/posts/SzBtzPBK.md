# 二、MMD 下载教程

## 1、下载 MMD 本体

MMD 官方页面：

[https://learnmmd.com/downloads/](https://learnmmd.com/downloads/)
![](assets/png/articles/d12fb172e08b.webp)

推荐版本：

- 
MMD 9.32 x64

- 
Windows 10/11 可正常使用

建议：

> 一定下载 64 位版本。

因为：

- 
插件兼容更好

- 
内存限制更少

- 
渲染更稳定

---

## 2、下载 DirectX 运行库

MMD 依赖老版 DirectX。

如果你打开软件闪退或者黑屏，大概率缺少运行库。

微软官方：

[从官方 Microsoft 下载中心下载 DirectX 终端用户运行时网页安装包](https://www.microsoft.com/en-us/download/details.aspx?id=35)

安装完成后重启电脑。

---

## 3、下载 MME（MMD 特效插件）

MME 全称：

> MikuMikuEffect

类似于：

- 
光影插件

- 
后期插件

- 
渲染增强

下载：

MME 下载页面

没有 MME：

- 
画面会很“塑料”

- 
没有高级光影

- 
无法使用 Ray 渲染

---

# 三、MMD 安装教程

## 1、解压软件

MMD 通常是压缩包。

建议解压到：

```
D:\MMD\
```

不要放：

- 
中文路径

- 
桌面

- 
OneDrive

- 
系统盘 Program Files

否则容易：

- 
模型乱码

- 
特效失效

- 
插件报错

---

## 2、启动软件

打开：

```
MikuMikuDance.exe
```

第一次启动如果出现：

- 
缺少 d3dx9_32.dll

- 
DirectX Error

说明没装 DirectX。

实时阴影

- 
AO 环境光

-

电影级质感

下载：

[https://github.com/ray-cast/ray-mmd](https://github.com/ray-cast/ray-mmd)
解压后：

把：

- 
Main

- 
Materials

- 
Effects

复制到：

```
UserFile\Accessory\
```

```
ray.x
```

```
MMEffect → 分配特效
```

# 十二、MMD 常见问题

## 1、模型变白

原因：

- 
缺贴图

- 
路径错误

解决：

- 
不要中文路径

- 
检查贴图文件夹

---

## 2、模型乱码

原因：

- 
日文编码问题

解决：

- 
系统区域改为日本

- 
使用 Locale Emulator

---

## 3、MMD 闪退

常见原因：

- 
DirectX 缺失

- 
显卡驱动太老

- 
插件冲突

---

## 4、模型穿模

属于正常现象。

解决方法：

- 
调整骨骼

- 
修改动作

- 
使用物理优化

# 十五、总结

MMD 虽然已经诞生很多年，但直到现在，它依然是二次元动画制作领域最经典的软件之一。

它最大的魅力就在于：

> “即使不会建模，也能做出属于自己的动画作品。”

对于新手来说：

MMD 的门槛远低于：

- 
Blender

- 
Maya

- 
C4D

但视觉表现依旧非常强。

如果你刚接触：
 建议先学：

- 
导模型

- 
导动作

- 
导镜头

等熟悉之后，再慢慢研究：

- 
Ray-MMD

高级渲染

 MMD 的魅力，真的很特别。
