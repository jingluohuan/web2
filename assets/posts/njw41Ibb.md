# 4.1 什么是 HTML 文档

HTML 文档就是一个 **以 **`.html`** 或 **`.htm`** 结尾的文本文件**。

例如：

```
index.html
about.html
contact.html
```

HTML 文档由 **标签（Tag）** 组成。

例如：

```

这是一个段落

```

这里包含：

部分

含义

`<p>`

开始标签

`</p>`

结束标签

中间内容

网页内容

浏览器会读取 HTML 标签，并将其 **渲染为网页页面**。

---

# 4.2 HTML 文档基本结构

一个标准 HTML 页面通常包含以下结构：

```

我的第一个网页

# Hello World

这是我的第一个 HTML 页面

```

HTML 页面主要由 **三个部分**组成：

部分

作用

DOCTYPE

声明 HTML 版本

head

网页信息

body

网页内容

# 4.4 HTML 标签

HTML 页面使用 **标签（Tag）** 来定义内容。

标签通常成对出现：

```

# 标题

```

结构：

```
内容
```

示例：

```

# 一级标题

段落

链接
```

---

# 4.5 HTML 标签层级

HTML 是一种 **嵌套结构语言**。

例如：

```

  
    

# 标题

    
段落

  

```

结构关系：

```
html
 └── body
      ├── h1
      └── p
```

这种结构称为：

**DOM（文档对象模型）**

---

# 4.6 head 标签

`<head>` 标签用于存放网页的 **元信息**。

例如：

```

网站标题

```

常见内容包括：

标签

作用

title

网页标题

meta

网页信息

link

加载 CSS

script

加载 JavaScript

浏览器不会直接显示这些内容。

---

# 4.7 title 标签

`title` 定义浏览器标签页标题。

例如：

```
我的博客
```

浏览器显示：

```
我的博客 - Chrome
```

同时，`title` 也非常重要：

- 
SEO 搜索引擎

- 
浏览器标签

- 
社交分享

---

# 4.9 body 标签

`body` 是网页 **可见内容区域**。

例如：

```

# 欢迎来到我的网站

这是一个 HTML 页面

```

浏览器最终显示的内容都来自 `body`。

# 4.12 HTML 代码规范

良好的代码规范可以提高可读性。

推荐规则：

### 1 缩进

```

    

# 标题

    
内容

```

### 2 标签小写

推荐：

```

内容

```

避免：

```
内容
```

### 3 结构清晰

建议每个标签独占一行。

# 4.13 HTML 文件命名

网页文件通常命名为：

```
index.html
```

原因：

当访问：

```
example.com
```

服务器默认加载：

```
example.com/index.html
```

常见页面：

```
index.html
about.html
contact.html
blog.html
```
