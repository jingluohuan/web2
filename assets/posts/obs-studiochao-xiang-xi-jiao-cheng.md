# OBS Studio超详细教程

**从下载安装到直播录制全流程实战指南**

## 一、OBS Studio 是什么？

**OBS Studio（Open Broadcaster Software）** 是一款**免费、开源、跨平台**的视频录制与直播推流软件，广泛用于：

- 
游戏直播（B站 / 抖音 / 虎牙 / Twitch）

- 
教学录屏 / 网课录制

- 
桌面演示 / PPT 讲解

- 
视频创作者内容制作

- 
会议录制、线上发布会

支持平台：

- 
Windows

- 
macOS

- 
Linux

OBS 的核心优势在于：

- 
完全免费、无水印

- 
高度自定义（场景 / 来源 / 滤镜 / 编码）

- 
专业级音视频控制

- 
强大的插件生态

---

## 二、OBS Studio 下载与安装

### 1. 官方下载地址

建议始终从**官网**下载，避免第三方修改版：

👉 [https://obsproject.com](https://obsproject.com)

选择对应系统版本：

- 
Windows（推荐 64 位）

- 
macOS（Intel / Apple Silicon）

- 
Linux（AppImage / Flatpak）

---

### 2. 安装过程说明

#### Windows 安装

- 
下载 `.exe` 安装包

- 
双击运行

- 
一路「下一步」即可

- 
桌面生成 OBS Studio 快捷方式

#### macOS 安装

- 
下载 `.dmg`

- 
拖动 OBS 到 Applications

- 
首次启动需要授权：

屏幕录制

- 
麦克风

- 
摄像头（如需要）

---

## 三、首次启动与自动配置向导

第一次启动 OBS，会弹出**自动配置向导**：

### 自动配置选项

- 
**用途选择**

仅录制

- 
录制 + 直播（推荐）

- 
**分辨率 / 帧率**

OBS 会根据电脑性能自动测试

- 
**编码器**

自动选择硬件或软件编码

👉 新手建议：**直接全部使用自动推荐**

后期可随时手动调整。

## 四、OBS 界面详解（核心概念）

OBS 的核心逻辑：

> **场景 → 来源 → 音视频 → 输出**

### 1. 主界面区域说明

区域

功能

预览窗口

实时显示画面

场景

场景集合（布局方案）

来源

画面/音频来源

混音器

麦克风、系统声音

场景切换

切换动画

控制

开始直播 / 录制

---

### 2. 场景（Scene）

**场景 = 一个画面布局方案**

例如：

- 
场景 1：全屏游戏

- 
场景 2：摄像头 + 游戏

- 
场景 3：PPT + 讲解

- 
场景 4：结束画面

👉 场景之间可以一键切换

---

### 3. 来源（Source）

**来源 = 场景中的具体元素**

常见来源：

- 
显示器捕获（全屏）

- 
窗口捕获（某个软件）

- 
游戏捕获（游戏）

- 
视频捕获设备（摄像头）

- 
图像 / 视频

- 
文本（标题）

- 
浏览器源（弹幕、通知）

---

## 五、最常用来源详细说明

### 1. 显示器捕获（桌面录制）

适合：

- 
教程录制

- 
演示操作

- 
PPT 讲解

设置要点：

- 
捕获显示器：选择主屏

- 
勾选「捕获鼠标光标」

⚠️ 注意：
会录到桌面所有内容，包括弹窗、隐私信息。

---

### 2. 窗口捕获

适合：

- 
单独录某个软件

- 
不想暴露桌面

优点：

- 
更干净

- 
不容易误录

缺点：

- 
全屏游戏可能不稳定

---

### 3. 游戏捕获（推荐游戏直播）

适合：

- 
全屏 / 无边框游戏

- 
低性能占用

模式：

- 
捕获特定窗口（推荐）

- 
捕获任何全屏应用

---

### 4. 摄像头添加

步骤：

- 
添加 → 视频捕获设备

- 
选择摄像头

- 
设置分辨率（如 1080p）

- 
调整画面大小与位置

---

### 5. 文本与图片

常用于：

- 
标题

- 
房间号

- 
欢迎语

- 
LOGO

支持：

- 
字体

- 
颜色

- 
滚动文本

---

## 六、音频系统详解（非常重要）

### 1. 音频来源分类

- 
**桌面音频**：系统声音、游戏音效

- 
**麦克风/辅助音频**：你的声音

---

### 2. 麦克风设置

路径：

```
设置 → 音频 → 麦克风

```

建议：

- 
只启用一个麦克风

- 
关闭未使用设备

---

### 3. 音量混音器

- 
红色：爆音（要避免）

- 
黄色：正常

- 
绿色：偏小

👉 麦克风建议保持在 -10dB ~ -6dB

---

### 4. 音频滤镜（强烈推荐）

右键麦克风 → 滤镜 → 添加：

#### 常用滤镜顺序

- 
噪声抑制

- 
噪声门

- 
压缩器

- 
限幅器

效果：

- 
消除底噪

- 
防止喷麦

- 
声音更稳定

---

## 八、编码器设置（性能关键）

路径：

```
设置 → 输出 → 输出模式：高级

```

### 1. 编码器类型

- 
**x264（CPU）**

- 
**NVENC（NVIDIA 显卡）**

- 
**AMD AMF**

- 
**Apple VT**

👉 有独显优先使用 **硬件编码**

---

### 2. 直播推荐参数

- 
码率：

720p60：3500 ~ 4500 kbps

- 
1080p60：6000 kbps

- 
关键帧间隔：2

- 
编码预设：Quality

---

### 3. 录制推荐参数

- 
录制格式：MKV（更安全）

- 
编码：硬件编码

- 
质量：高质量

---

## 十二、常见问题与解决方案

### 1. 黑屏问题

原因：

- 
显卡切换

- 
权限不足

解决：

- 
Windows 设置 OBS 使用独显

- 
macOS 授权屏幕录制

---

### 2. 声音延迟

解决：

- 
音频高级属性

- 
手动延迟补偿

---

### 3. 卡顿 / 掉帧

优化：

- 
降低分辨率

- 
降低码率

- 
使用硬件编码
