```

```

---

### 强调（语义更强）

```
**重要内容**
```

区别：

标签

含义

b

视觉加粗

strong

```

```

```

区别：

标签

含义

视觉斜体

em

语义强调

推荐：

```

```

# 5.7 删除线

HTML 可以显示删除文本。

标签：

```
~~
```

示例：

```

原价：199元~~
现价：99元

```

显示：

```
原价： ~199元~
现价：99元
```
