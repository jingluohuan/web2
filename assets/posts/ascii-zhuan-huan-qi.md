### 一、软件功能简介

本工具为 Windows 平台下的控制台 ASCII 编码转换程序，支持如下功能：

功能编号

功能名称

描述

1

字符转 ASCII 码

输入一个字符，程序返回该字符对应的 ASCII 数值

2

ASCII 码转字符

输入一个整数 ASCII 码值，返回对应的字符

3

字符串转 ASCII 码序列

输入一个字符串，返回对应的 ASCII 数值列表

4

ASCII 码序列转字符串

输入一串 ASCII 数值（用空格分隔），还原为字符串

5

退出

结束程序运行

---

### 二、运行方式

1.双击运行 ASCII转换器.exe（或在命令行中执行）

2.程序将显示主菜单

3.按提示输入功能编号（1~5），进入相应功能

4.根据提示完成输入

5.返回主菜单或选择退出

### 三、示例操作

#### 示例 1：字符转 ASCII

```
请选择功能（1-5）：1
请输入一个字符：A
字符 'A' 的 ASCII 码是：65

```

#### 示例 2：ASCII 转字符

```
请选择功能（1-5）：2
请输入一个 ASCII 码：66
ASCII 码 66 对应的字符是：B

```

#### 示例 3：字符串转 ASCII 序列

```
请选择功能（1-5）：3
请输入字符串：Hello
ASCII 序列是：72 101 108 108 111

```

#### 示例 4：ASCII 序列转字符串

```
请选择功能（1-5）：4
请输入 ASCII 序列（空格分隔）：72 105
转换后的字符串是：Hi

```
